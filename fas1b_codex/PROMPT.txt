## ANALYS

### Från HFD-mal_nr.md:
1. Single: `4033-09`
2. Lista komma: `6963-15, 6969-15`
3. Lista "och": `6980-24 och 6981-24`
4. Lista "samt": `A samt B`
5. Intervall en-dash: `6107–6109-23`
6. Intervall dubbel-dash: `6159--6160-14`
7. Intervall enkelt: `4569-4571-22`
8. Kombinationer: `6578-14, 6159--6160-14`, `7550–7558-21 samt 664–669-22`

### Från courts.py:
- HD: `X NNNN-NN` (T, B, Ö, P som prefix)
- AD: `A NNN/NN` (slash istället för dash)
- MÖD: `M NNNN-NN`
- MMOD: `M NNNNN-NN`, `UM NNNNN-NN` (längre prefix)
- MDO: `YYYY-N` (år-nummer utan 2-siffrig årssuffix)

## STEG

### 1. Förbättra regex-patterns

**SINGLE_PATTERNS:**
- Behåll nuvarande patterns
- Lägg till stöd för längre prefix (UM, PMT, etc.)

**RANGE_PATTERN:**
- Behåll nuvarande
- Verifiera att alla tre intervalltecken (–, --, -) fungerar

### 2. Förbättra parse_single()

- Behåll prefix där det finns (T 1234-22)
- Normalisera whitespace (T  1234-22 → T 1234-22)
- Returnera None om inget match

### 3. Förbättra parse_range()

- Hantera alla intervalltecken
- Returnera (start, end, year)

### 4. Förbättra expand_range()

- Verifiera att start ≤ end (swappa annars)
- Returnera expanderad lista

class TestMalnummerParserHFD:
    """HFD-specifika tester från HFD-mal_nr.md"""
    
    def test_single_basic(self):
        assert parse("4033-09") == ["4033-09"]
    
    def test_lista_komma(self):
        assert parse("6963-15, 6969-15") == ["6963-15", "6969-15"]
    
    def test_lista_och(self):
        assert parse("6980-24 och 6981-24") == ["6980-24", "6981-24"]
    
    def test_lista_samt(self):
        assert parse("A samt B") == ["A", "B"]
    
    def test_intervall_endash(self):
        assert parse("6107–6109-23") == ["6107-23", "6108-23", "6109-23"]
    
    def test_intervall_doubledash(self):
        assert parse("6159--6160-14") == ["6159-14", "6160-14"]
    
    def test_intervall_singledash(self):
        # Svårt att skilja från single - kräver kontext
        pass
    
    def test_kombination_1(self):
        result = parse("6578-14, 6159--6160-14")
        assert "6578-14" in result
        assert "6159-14" in result
        assert "6160-14" in result
    
    def test_kombination_2(self):
        result = parse("7550–7558-21 samt 664–669-22")

        assert "669-22" in result
